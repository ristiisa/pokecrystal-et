# Custom title-screen assets

Drop a file named `logo.png` here to replace the Pokémon title logo.

- Export it however is convenient (Photoshop RGB PNG is fine — colors and
  anti-aliasing don't matter). `apply_assets.py` snaps every pixel to the four
  DMG greys the GBC 2bpp title tiles allow (`#000 #555 #AAA #FFF`) and installs
  it to `gfx/title/logo.png` at build time.
- Ideal canvas is **160x64 px** (or a clean multiple like 320x128); other sizes
  are downscaled with LANCZOS first. Design in 4 flat greys for crispest results.
- The title screen recolors these greys via a GBC palette at runtime, so lightness
  (not hue) is what carries: white = lightest area, black = darkest. If it looks
  inverted on the title screen, invert the source.

Regenerated by `tools/writeback.py` -> `apply_assets.py`; never committed to
`gfx/`. Only `tools/` is committed.
